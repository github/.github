#. [Wiki] There are three types of locations, each represented by an item:
#. [Wiki] * the main value of a statement
#. [Wiki] * the qualifiers of a statement
#. [Wiki] * the references of a statement
#. [Wiki] Please avoid phrasing the message in a way that depends on the labels of those items, since they may change in the future (i.&nbsp;e., don’t try to use them to build full sentences, even though the current labels might allow it).
#. [Wiki] 
#. [Wiki] Parameters:
#. [Wiki] * $1 is the property that has been used in an unexpected location.
#. [Wiki] * $2 is the location where the property was found.
#. [Wiki] * $3 is the number of allowed locations for the property.
#. [Wiki] * $4 is an HTML list of all allowed locations for the property.
#. [Wiki] * $5, $6 etc. are the individual allowed locations for the property.
msgctxt "wbqc-violation-message-property-scope"
msgid "The property $1 should not be used in this location ($2). The only valid {{PLURAL:$3|location|locations}} for this property {{PLURAL:$3|is $5.|are: $4}}"
msgstr ""
